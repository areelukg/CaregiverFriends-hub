วิธีตรวจเช็กอาการว่า “ฉุกเฉินจริงหรือไม่” และขั้นตอนปฐมพยาบาลเบื้องต้น

เมื่อเกิดเหตุการณ์ไม่คาดคิด สิ่งสำคัญที่สุดคือ “การตั้งสติ” เพื่อแยกแยะระดับความรุนแรงของอาการ การประเมินที่ถูกต้องจะช่วยให้ผู้สูงอายุได้รับการรักษาที่ตรงจุดและทันเวลา

🚨 อาการฉุกเฉินวิกฤต (โทร 1669 ทันที)

  • หมดสติ ปลุกไม่ตื่น ไม่มีการตอบสนอง
  • เจ็บแน่นกลางหน้าอก หายใจไม่ออก เหงื่อแตก
  • ปากเบี้ยว แขนขาอ่อนแรง พูดไม่ชัด (FAST)
  • สำลักอาหาร ทางเดินหายใจอุดกั้น ชักเกร็ง

🏥 อาการไม่วิกฤต (ไป รพ. เอกชนใกล้บ้าน)

  • มีไข้สูง หนาวสั่น แต่ยังรู้ตัว พูดคุยรู้เรื่อง
  • หกล้มมีแผลฟกช้ำ แต่ขยับแขนขาได้ ไม่มีกระดูกผิดรูป
  • ถ่ายเหลวเล็กน้อย ปัสสาวะยังออก ไม่มีมูกเลือดปน
  • เวียนศีรษะ บ้านหมุน จากการเปลี่ยนท่า

ขั้นตอนปฐมพยาบาลเบื้องต้น

1. กรณีผู้สูงอายุหกล้ม (Falls)

ห้ามดึงให้ลุกขึ้นทันที ให้ประเมินการบาดเจ็บบริเวณศีรษะ คอ และสะโพก ตรวจดูว่ามีการขยับนิ้วมือและเท้าได้ตามปกติหรือไม่ หากมีอาการปวดรุนแรงให้ประคองให้อยู่นิ่งที่สุด

2. กรณีสิ่งแปลกปลอมอุดกั้นทางเดินหายใจ (Choking)

หากยังไอได้ ให้กระตุ้นให้ไอแรงๆ ห้ามใช้นิ้วล้วงในลำคอหากมองไม่เห็นสิ่งแปลกปลอม หากหายใจไม่ได้และไม่มีเสียง ให้ยืนด้านหลังแล้วทำท่ารัดกระตุกหน้าท้อง (Heimlich Maneuver)

การตรวจเช็กอุจจาระประจำวัน (Bristol Scale)

ลักษณะอุจจาระสะท้อนถึงระดับน้ำในร่างกาย ภาวะการดูดซึม และสุขภาพของทางเดินอาหาร การสังเกตรูปแบบเป็นประจำจะช่วยป้องกันภาวะลำไส้อุดตันและตรวจพบความผิดปกติได้ตั้งแต่ระยะแรก

ประเมินอาการฉุกเฉินวิกฤต (Triage Checklist)

หากพบสัญญาณเตือนข้อใดข้อหนึ่งต่อไปนี้ ให้กดโทร 1669 ทันที:

โทร 1669 ทันที

เกณฑ์ประเมินลักษณะอุจจาระ (Bristol Stool Form)

เปรียบเทียบรูปทรงเพื่อประเมินภาวะการขับถ่าย

Type 1: เม็ดแข็งกระสุน คล้ายขี้แพะ

ท้องผูกรุนแรง: อุจจาระตกค้างในลำไส้นาน ขาดน้ำอย่างมาก แนะนำจิบน้ำเพิ่มและปรึกษาแพทย์

Type 2: ทรงไส้กรอกแต่เป็นก้อนตะปุ่มตะป่ำ

ท้องผูกปานกลาง: เริ่มมีการเกาะตัวแข็ง ขับถ่ายต้องเบ่ง แนะนำเพิ่มใยอาหารชนิดละลายน้ำ

Type 3: ทรงไส้กรอกมีรอยแยกที่ผิว

ปกติ (เกณฑ์ดี): ขับถ่ายได้สะดวก ไม่มีอาการปวดเบ่ง ลำไส้มีความชุ่มชื้นพอเหมาะ

Type 4: ผิวเรียบนุ่ม คล้ายกล้วยหอม

สมบูรณ์แบบ (Ideal): สุขภาพลำไส้และระบบย่อยอาหารทำงานได้อย่างมีประสิทธิภาพสูงสุด

Type 5: ชิ้นนุ่มขอบตัดชัดเจน ถ่ายง่าย

ค่อนข้างเหลว: ลำไส้บีบตัวเร็วไปเล็กน้อย หรือได้รับกากใยไม่เพียงพอ สังเกตอาการต่อเนื่อง

Type 6: กึ่งเหลวกึ่งก้อน ขอบขุยยุ่ย

เริ่มท้องเสีย (Diarrhea): มีการอักเสบหรือติดเชื้อ ให้จิบผงเกลือแร่ ORS เพื่อชดเชยน้ำ
