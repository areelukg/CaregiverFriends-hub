วิธีตรวจเช็กอาการว่า “ฉุกเฉินจริงหรือไม่” และขั้นตอนปฐมพยาบาลเบื้องต้น

เมื่อเกิดเหตุการณ์ผิดปกติกับผู้สูงวัย สิ่งสำคัญที่สุดคือ “การตั้งสติ” เพื่อแยกแยะระดับความรุนแรงของอาการ การประเมินที่ถูกต้องจะช่วยให้ผู้สูงอายุได้รับการดูแลรักษาอย่างปลอดภัยและเหมาะสม

🚨 อาการฉุกเฉินวิกฤต (โทร 1669 ทันที)

  • หมดสติ ปลุกไม่ตื่น ไม่มีการตอบสนอง
  • เจ็บแน่นกลางหน้าอกรุนแรง หายใจไม่ออก
  • ปากเบี้ยว แขนขาอ่อนแรงครึ่งซีก พูดไม่ชัด (FAST)
  • สำลักอาหาร ทางเดินหายใจอุดกั้น ชักเกร็ง

🏥 อาการไม่วิกฤต (ไป รพ. เอกชนใกล้ฉัน)

  • มีไข้สูง หนาวสั่น แต่ยังรู้ตัวดี พูดคุยรู้เรื่อง
  • หกล้มมีแผลถลอก แต่ขยับแขนขาได้ ไม่มีกระดูกผิดรูป
  • ถ่ายเหลวเล็กน้อย ปัสสาวะยังออก ไม่มีมูกเลือด
  • เวียนศีรษะจากการเปลี่ยนอิริยาบถ

ขั้นตอนปฐมพยาบาลเบื้องต้น

1. กรณีผู้สูงอายุหกล้ม (Falls)

ห้ามดึงให้ลุกขึ้นทันที ให้ประเมินการบาดเจ็บบริเวณศีรษะ คอ และสะโพก สังเกตการขยับของนิ้วมือและเท้า หากบ่นปวดสะโพกหรือหลังรุนแรง ให้ประคองให้อยู่นิ่งและโทรขอความช่วยเหลือ

2. กรณีสำลัก / สิ่งแปลกปลอมอุดกั้นทางเดินหายใจ (Choking)

หากยังไอได้ ให้กระตุ้นให้ไอแรงๆ ห้ามใช้นิ้วล้วงในลำคอหากมองไม่เห็นสิ่งแปลกปลอม หากหายใจไม่ได้และส่งเสียงไม่ออก ให้ยืนด้านหลังแล้วทำท่ารัดกระตุกหน้าท้อง (Heimlich Maneuver) ทันที

การสังเกตรูปทรงและสีของอุจจาระ (Bristol Scale)

ลักษณะอุจจาระสะท้อนถึงการดื่มน้ำ การดูดซึมสารอาหาร และการทำงานของระบบลำไส้ การหมั่นสังเกตเป็นประจำจะช่วยป้องกันภาวะท้องผูกรุนแรงและสังเกตความผิดปกติได้ล่วงหน้า

ข้อสงวนสิทธิ์ทางการแพทย์และการใช้งาน (Medical Disclaimer)

เว็บไซต์และหน้าเพจ ElderCGF (เพื่อนดูแลผู้สูงวัย CaregiverFriends) จัดทำขึ้นเพื่อวัตถุประสงค์ในการแบ่งปันประสบการณ์และรวบรวมองค์ความรู้เบื้องต้นสำหรับผู้ดูแลเท่านั้น ผู้จัดทำมิใช่แพทย์ ผู้ประกอบวิชาชีพเวชกรรม หรือสถานพยาบาล

ข้อมูลทั้งหมดไม่สามารถนำไปใช้ทดแทนการวินิจฉัย การรักษา หรือคำแนะนำจากแพทย์ผู้เชี่ยวชาญได้ หากผู้สูงอายุมีอาการเจ็บป่วยหรือเหตุฉุกเฉิน โปรดโทรแจ้งสายด่วน 1669 หรือนำส่งโรงพยาบาลเพื่อรับการตรวจรักษาจากแพทย์โดยตรงทันที

ประเมินอาการฉุกเฉินวิกฤต (Triage Checklist)

หากพบสัญญาณเตือนข้อใดข้อหนึ่งต่อไปนี้ ให้กดโทร 1669 ทันที:

โทร 1669 ทันที

เกณฑ์ประเมินลักษณะอุจจาระ (Bristol Stool Form)

เปรียบเทียบรูปทรงเพื่อประเมินภาวะการขับถ่าย

Type 1: เม็ดแข็งกระสุน คล้ายขี้แพะ

ท้องผูกรุนแรง: ขาดน้ำอย่างมาก แนะนำจิบน้ำบ่อยๆ และปรึกษาแพทย์หากถ่ายไม่ออกต่อเนื่อง

Type 2: ทรงไส้กรอกแต่เป็นก้อนตะปุ่มตะป่ำ

ท้องผูกปานกลาง: เริ่มมีการเกาะตัวแข็ง ขับถ่ายต้องออกแรงเบ่ง ควรเพิ่มอาหารที่มีกากใย

Type 3: ทรงไส้กรอกมีรอยแยกที่ผิว

ปกติ (เกณฑ์ดี): ถ่ายได้สะดวก ลำไส้มีความชุ่มชื้นพอเหมาะ

Type 4: ผิวเรียบนุ่ม คล้ายกล้วยหอม

สมบูรณ์แบบ (Ideal): ระบบย่อยและดูดซึมทำงานมีประสิทธิภาพสูงสุด

Type 5: ชิ้นนุ่มขอบชัด ถ่ายง่าย

ค่อนข้างเหลว: ลำไส้บีบตัวเร็วไปเล็กน้อย ให้สังเกตอาการต่อเนื่อง

Type 6: กึ่งเหลวกึ่งก้อน ขอบขุยยุ่ย

เริ่มท้องเสีย (Diarrhea): มีการอักเสบหรือติดเชื้อ ควรจิบผงเกลือแร่ ORS ชดเชยน้ำ
